# Playwright TypeScript 2

A small TypeScript starter project with simple demo scripts.

## Commands

- `npm run build` compiles TypeScript from `src` into `dist`.
- `npm start` builds and runs the hello-world demo.
- `npm test` type-checks the project without writing output files.
- `npm run clean` removes generated build output.

## Project Structure

- `src/` contains the TypeScript source files.
- `dist/` contains generated JavaScript after a build.
